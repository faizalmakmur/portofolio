📌 Portfolio Website

This repository contains my personal portfolio website developed to showcase my background, technical skills, and web development projects. The website is designed as a professional digital profile that highlights my experience as an Information Technology graduate with a strong interest in web development, UI/UX design, and full stack development.

The portfolio presents a collection of academic, personal, and freelance projects, complete with project descriptions, technologies used, and live demo or GitHub links. Each section is structured to provide clear information for recruiters, HR professionals, and collaborators who want to understand my technical capabilities and development approach.

The website is built with a clean, modern, and responsive design, ensuring optimal display across desktop, tablet, and mobile devices. Special attention is given to usability, accessibility, and performance to create a smooth user experience. Interactive elements and animations are implemented carefully to enhance visual appeal without compromising website performance.

From a technical perspective, this portfolio is developed using HTML5, CSS3, JavaScript, and Bootstrap, following best practices in front-end development. The code structure is organized, maintainable, and easy to extend for future improvements, such as adding new projects, integrating APIs, or connecting with a backend service.

Overall, this portfolio website serves as a central hub for presenting my professional profile, demonstrating my technical expertise, and supporting my career growth in the field of web development and information technology.
